About this tool

Will every PDF become smaller?

Not necessarily. PDFs that are already highly optimized may see little reduction. Nexauren reports the actual result instead of promising a fixed percentage.

Does it preserve selectable text?

The compressed copy is rebuilt from rendered pages, so text can become non-selectable. Keep the original when searchable text is important.

Are my files uploaded?

No. The tool is designed to load, render and create the result in your browser.
