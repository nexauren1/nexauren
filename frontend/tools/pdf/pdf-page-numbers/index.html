FAQ

Can I start numbering from another number?

Yes. Set the starting number before creating the PDF.

Does it change my original PDF?

No. Nexauren creates a new numbered copy and leaves your original file untouched.

Can I number every page?

Yes. Page numbers are added to every page of the selected document.
