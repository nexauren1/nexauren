FAQ

Does cropping delete content?

It changes the visible page box. Content outside the new box is no longer visible in the cropped document.

Are my files uploaded?

No. This tool performs the crop locally in your browser.

What units are used?

Margins use PDF points. 72 points equals 1 inch.
