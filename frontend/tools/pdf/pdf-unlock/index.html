FAQ

Can it recover a forgotten password?

No. Nexauren Unlock is not a password-cracking tool. You need the correct password or authorization to unlock the document.

Does the PDF get uploaded?

No. The intended processing path is browser-local WebAssembly.

What if the password is wrong?

The tool reports the failure and does not create a download.
